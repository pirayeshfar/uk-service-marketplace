# UK Service Marketplace Web App

A modern, full-featured service marketplace platform designed for the United Kingdom, inspired by standard gig-economy models. It connects customers with local verified service providers across various UK cities.

## Key Features
- **Smart Dynamic Categorization:** Categories automatically adapt based on active database listings.
- **Provider Onboarding & Verification:** Multi-step registration including UK city selection, ID info, skills, availability, and payout bank details pending admin approval.
- **Admin Control Panel:** Comprehensive dashboard for managing service requests, pricing, commissions, provider databases, and dynamic bank account card details.
- **Interactive Booking & Pricing:** Transparent booking flow with admin-defined pricing and dynamic bank transfer simulation cards.
- **Responsive Business Theme:** Clean, corporate, and trust-building UI/UX built for standard web and mobile viewports.
